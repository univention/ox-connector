.. _helm-ref-openxchange:

``openXchange``
---------------

.. envvar:: openXchange.auth.existingSecret.keyMapping.password

   Key in the existing Secret that contains the OX Admin password. Set this value to use a key with a different name.

   **Default value**: ``null``


.. envvar:: openXchange.auth.existingSecret.name

   Name of an existing Secret that contains the OX Admin password. The value in "openXchange.auth.password" is ignored if this value is set.

   **Default value**: ``null``


.. envvar:: openXchange.auth.password

   Password of the OX Admin user.

   **Default value**: ``null``


.. envvar:: openXchange.auth.username

   Username of the OX Admin user. The OX Admin user can create, modify, and delete contexts and must already exist.

   **Default value**: ``"oxadminmaster"``


.. envvar:: openXchange.database.existingSecret.keyMapping.OX_CONNECTOR_DB

   Key in the existing Secret that holds the connection URL. Defaults to the key the chart uses in its own Secret.

   **Default value**: ``null``


.. envvar:: openXchange.database.existingSecret.name

   Name of an existing Secret that contains the SQLAlchemy DB connection URL. The value in "openXchange.oxDbConnectionString" is ignored if this value is set. Providing the URL this way keeps the database password out of the rendered manifests.

   **Default value**: ``null``


.. envvar:: openXchange.deleteNonOxUsers

   Delete users from OX when "Activate User in OX" is unchecked. When disabled, the user is deactivated (if it existed) instead.

   **Default value**: ``true``


.. envvar:: openXchange.domainName

   OX mail domain that the connector uses to generate email addresses.

   **Default value**: ``null``


.. envvar:: openXchange.logLevel

   OX Connector log level. Choose from "DEBUG", "INFO", "WARNING", and "ERROR".

   **Default value**: ``"INFO"``


.. envvar:: openXchange.mappings.groupIdentifier

   UDM group property that the connector uses as the unique group identifier in OX.

   **Default value**: ``"name"``


.. envvar:: openXchange.mappings.sharedAccountIdentifier

   UDM shared account property that the connector uses as the unique shared account identifier in OX.

   **Default value**: ``"name"``


.. envvar:: openXchange.mappings.userIdentifier

   UDM user property that the connector uses as the unique user identifier in OX.

   **Default value**: ``"username"``


.. envvar:: openXchange.oxDbConnectionString

   SQLAlchemy DB connection URL for the OX connector. Ignored if "openXchange.database.existingSecret.name" is set.

   **Default value**: ``null``


.. envvar:: openXchange.oxDefaultContext

   Default OX context for users. The context must already exist.

   **Default value**: ``"10"``


.. envvar:: openXchange.oxDeputyPermissions

   Enable provisioning of OX deputy permissions.

   **Default value**: ``false``


.. envvar:: openXchange.oxImapServer

   Default IMAP server for new users if no IMAP server is set on the user object.

   **Default value**: ``null``


.. envvar:: openXchange.oxLanguage

   Default language for new users.

   **Default value**: ``"de_DE"``


.. envvar:: openXchange.oxLocalTimezone

   Default time zone for new users.

   **Default value**: ``"Europe/Berlin"``


.. envvar:: openXchange.oxSharedAccount

   Enable provisioning of OX shared accounts.

   **Default value**: ``true``


.. envvar:: openXchange.oxSmtpServer

   Default SMTP server for new users if no SMTP server is set on the user object.

   **Default value**: ``null``


.. envvar:: openXchange.oxSoapServer

   Server where OX App Suite is installed.

   **Default value**: ``null``


.. envvar:: openXchange.stopOnError

   OX Connector error handling behavior. When activated, the connector stops processing on the first error instead of continuing.

   **Default value**: ``false``

.. _helm-ref-probes:

``probes``
----------

.. envvar:: probes.liveness.exec.command

   Command for the liveness probe.

   **Default value**: ``["/bin/sh", "-c", "exit 0\n"]``


.. envvar:: probes.liveness.failureThreshold

   Number of failed liveness probes before Kubernetes restarts the container.

   **Default value**: ``3``


.. envvar:: probes.liveness.initialDelaySeconds

   Initial delay in seconds before the liveness probe starts.

   **Default value**: ``120``


.. envvar:: probes.liveness.periodSeconds

   Interval in seconds between liveness probe executions.

   **Default value**: ``30``


.. envvar:: probes.liveness.successThreshold

   Number of successful liveness probes required to mark the container healthy.

   **Default value**: ``1``


.. envvar:: probes.liveness.timeoutSeconds

   Timeout in seconds for the liveness probe.

   **Default value**: ``3``


.. envvar:: probes.readiness.exec.command

   Command for the readiness probe.

   **Default value**: ``["/bin/sh", "-c", "exit 0\n"]``


.. envvar:: probes.readiness.failureThreshold

   Number of failed readiness probes before Kubernetes marks the container not ready.

   **Default value**: ``30``


.. envvar:: probes.readiness.initialDelaySeconds

   Initial delay in seconds before the readiness probe starts.

   **Default value**: ``30``


.. envvar:: probes.readiness.periodSeconds

   Interval in seconds between readiness probe executions.

   **Default value**: ``15``


.. envvar:: probes.readiness.successThreshold

   Number of successful readiness probes required to mark the container ready.

   **Default value**: ``1``


.. envvar:: probes.readiness.timeoutSeconds

   Timeout in seconds for the readiness probe.

   **Default value**: ``3``
